# Notebooks

Recommended execution order:

1. `00_data_preparation.ipynb`
2. `01_logit_benchmark.ipynb`
3. `03_ebm_pipeline.ipynb`
4. `04_bilstm_pipeline.ipynb`

The notebooks were statically checked before GitHub upload for consistency between markdown descriptions and code cells, path portability, and syntax validity.

If the notebooks are moved into this `notebooks/` subdirectory, start Jupyter from the repository root or configure `DATA_DIR` / `BASE_DIR` so that the notebooks can find the required input CSV files.
